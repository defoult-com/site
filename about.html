The defOult project began as a one-person hobby project in pursuit of the perfect standalone hardware sequencer.

The primary goal was to create a fast and intuitive workflow where any function can be reached in no more than two button presses, with no menu diving. Some of the more advanced features are accessed through key combinations—a trade-off that makes it possible to fit a powerful feature set into a clean and minimal user interface.

Another core principle of the hardware version is its open-source firmware. If a design decision ever proves questionable, or if the original developer loses interest, anyone with the necessary skills will be able to improve and expand the project.

What you see on this website is a prototype of the hardware sequencer's workflow. It is intended more as a proof of concept than a finished product, but it is already a fun and capable tool to experiment with.

Rather than trying to reinvent the sequencer, defOult combines ideas and features from a variety of existing sequencers, along with several original concepts, all organized into a more coherent and efficient workflow.

As the project evolved, it became clear that the same workflow translated well to desktop and mobile devices. The interface was therefore adapted to provide a user-friendly experience across different platforms.

There are still plenty of bugs to fix and many ideas waiting to be implemented.

The long-term vision is to rewrite the codebase from scratch with the help of an experienced software developer and eventually release defOult as a polished application for desktop and mobile platforms. The application will be paid, with all proceeds helping to fund the development of the physical hardware. The web version, however, will always remain free.

Development of the physical hardware is still in its early stages, and many aspects of the design are expected to evolve as the project progresses.
