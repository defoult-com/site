Hi, my name is Krum, and I'm from Bulgaria.

I'm a 3D animator by profession and have been making music for over 25 years. Synthesizers and drum machines have always been a passion of mine.

The defOult project started while searching for a hardware sequencer. None of the available options felt quite right, so the solution was to design one from scratch.

The main goal is to create a fast, intuitive workflow where any function can be reached in no more than two button presses, with no menu diving. Some of the more advanced features are accessed through key combinations — a small trade-off that allows a powerful feature set to fit within a clean and minimal user interface. Another core principle of the hardware version is open-source firmware. If there is ever a design decision that doesn't make sense, or if the original developer loses interest, anyone with the necessary skills can improve or fix it.

What you see on this website is a prototype of the hardware sequencer’s workflow — more of a proof of concept than a finished product, but it is still really fun to play with.

It’s not something entirely new or unheard of, but rather a combination of features taken from sequencers I’ve personally enjoyed, along with a few original ideas, all organized into a more coherent and efficient workflow.

As the project evolved, it became clear that the same workflow also works well as a desktop and mobile application, so the interface was adapted to be more user-friendly across different devices.

Programming isn't my profession, so the prototype was built with the help of AI. There are still plenty of bugs to fix and many ideas for new features, but other major projects need attention as well, so the decision was made to release it in its current state.

The long-term goal is to have the code rewritten from scratch by an experienced programmer and eventually release defOult as a polished application for desktop and mobile devices. The app will be paid, with all proceeds helping to fund the development of the physical hardware. The web version, however, will always remain free.

The physical hardware is being developed in collaboration with an experienced hardware engineer friend. It's still in the very early stages of development, so many aspects of the design are expected to evolve as the project moves forward.
